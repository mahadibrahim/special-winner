Class/camp session open

You own this

When: About 20 minutes before the scheduled session start

There's a checklist for this — see the checklist slides.

If something goes wrong: If headcount exceeds the ratio cap (e.g., a Coach no-show), the Coach holds the start and escalates to Event Lead; if unreachable, Venue Manager per the standard handoff ladder. A session never starts over-ratio.

  1. Arrive early enough to finish this checklist before players are
  2. dropped off. Pull today's roster in /coach/attendance.
  3. Walk the playing space: wet spots, debris, damaged fixtures. Report
  4. anything unsafe to the venue manager before setup.
  5. Stage equipment for the first activity: age-appropriate balls, cones,
  6. pinnies. Confirm a first-aid kit is at the field/court.
  7. Greet players as they arrive and mark attendance against the roster.
  8. For clinics/drop-ins, only players registered by front of house
  9. (walk-on registration) may join.
  10. Before play begins, check headcount against the staffing ratio and
  11. class cap for the age group — ages 4-6: 1 coach per 4 players, class
  12. of 8-10 max; ages 7-9: 1:5, 10-12 max; ages 10-12: 1:6, 12-14 max.
  13. For drop-in/clinic sessions, re-check as walk-ons join during the
  14. intake window.
  15. If over-ratio, hold the start and escalate per the escalation path.

Your day: in game

  • Camp group rotation — You own this

Camp group rotation

You own this

When: At each scheduled activity-block transition on the camp daily schedule

If something goes wrong: If headcount does not match the group roster, all play stops immediately and the Coach escalates to Event Lead and Venue Manager; the search for the missing child takes priority over every other activity on site.

  1. Two minutes before the scheduled transition, wind down the current
  2. activity and gather the group (transitions are listed on the camp
  3. daily schedule, e.g., full-day blocks like 9:45-10:45 technical
  4. session, 11:00-11:45 small-sided games).
  5. Collect any equipment that belongs to the current station; carry
  6. group gear (water cooler, clipboard/roster) with the group.
  7. Walk the group to the next station together — no child moves between
  8. stations alone.
  9. At the new station, count heads against the group roster before play
  10. resumes. Ages 4-6 groups are 8-10 per coach, ages 7-9 are 10-12,
  11. ages 10-12 are 12-14 — know your expected number before you move.
  12. If the count matches, increment the rotation counter and start the
  13. next activity. If it does not, stop and escalate per the escalation
  14. path.
  15. For ages 4-6, plan activity changes every 8-10 minutes within a
  16. station; the roster headcount is only required at station moves.

Your day: post game

  • Class/camp session close — You own this

Class/camp session close

You own this

When: At the scheduled end of the session

There's a checklist for this — see the checklist slides.

If something goes wrong: If a Player has no Parent/guardian at pickup, the Coach stays with the Player and escalates to Event Lead; if unreachable, Venue Manager per the standard handoff ladder. The Coach never leaves before the last Player has been picked up.

  1. End the session on time and on a positive note (cooldown, review,
  2. at-home challenge per the session structure).
  3. Release each player only to a recognized parent/guardian. No child
  4. leaves unaccompanied. Stay with any un-picked-up player and escalate
  5. per the escalation path.
  6. Use pickup as the parent handoff: one sentence on what the session
  7. worked on and the at-home challenge (keep it fun and brief,
  8. 10-15 min).
  9. Tear down: count balls, cones, pinnies, and portable goals back into
  10. storage. Flag missing or damaged equipment to facilities.
  11. Sweep the playing area for personal items; anything found goes to
  12. lost and found.
  13. Finalize attendance and log coach notes in the coach portal while
  14. the session is fresh. Leave the space ready for the next group.

Checklist: chk.class_session_close

  • Every player released to a recognized parent/guardian (no child leaves unaccompanied)
  • Parents told what the session worked on and given the at-home challenge
  • Equipment counted and returned to storage (balls, cones, pinnies, portable goals)
  • Playing area swept for personal items; anything found goes to lost and found
  • Coach notes / attendance finalized in the coach portal
  • Space left ready for the next group (trash cleared, fixtures back in place)

Checklist: chk.class_session_open

  • Today's roster and attendance sheet open in /coach/attendance
  • Playing space walked for hazards (wet spots, debris, damaged fixtures)
  • Session equipment staged (balls sized for the age group, cones, pinnies)
  • First-aid kit present at the field/court
  • Attendance recorded against the roster
  • Headcount vs. staffing within program ratio and class cap (ages 4-6: 1:4, 8-10 max; ages 7-9: 1:5, 10-12 max; ages 10-12: 1:6, 12-14 max)

Safety & escalation

  • If Event Lead unreachable, escalate to Venue Manager per the standard handoff ladder.
  • If a Player has no Parent/guardian at pickup, the Coach stays with the Player and escalates to Event Lead; if unreachable, Venue Manager per the standard handoff ladder. The Coach never leaves before the last Player has been picked up.
  • If headcount does not match the group roster, all play stops immediately and the Coach escalates to Event Lead and Venue Manager; the search for the missing child takes priority over every other activity on site.
  • If headcount exceeds the ratio cap (e.g., a Coach no-show), the Coach holds the start and escalates to Event Lead; if unreachable, Venue Manager per the standard handoff ladder. A session never starts over-ratio.

You may need to escalate to: Coach, Event Lead, Parent, Player, Venue Manager
