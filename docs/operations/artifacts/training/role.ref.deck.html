Safety & escalation

  • If event_lead unreachable, escalate to role.venue_manager per the standard handoff ladder; backup ref pulled from standby pool if scheduled ref no-shows.
  • If primary ref unable to operate clock, the assistant ref or event lead takes over; escalate to role.venue_manager only if the match must be paused.
  • If ref cannot complete the form, role.event_lead captures the ref's verbal account and files; escalate to role.director for any ejection carrying multi-match suspension.
  • If ref unable to sign, event_lead captures a co-attestation with the ref's verbal confirmation and escalates to role.venue_manager for any contested score.
  • If the entry app fails, ref keeps a paper tally and event_lead enters the running score in batch; escalate to role.venue_manager if the issue persists across matches.
