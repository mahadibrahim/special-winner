# Research

Dated, cited briefs produced by `/curriculum-refinery research`, one file
per sweep: `YYYY-MM-DD-brief.md`. Every finding in a brief carries a
citation URL and a note on which of our content it's relevant to; findings
that survive the adversarial staleness/citation filter get appended as
proposed directives under a matching `## Proposed (research YYYY-MM-DD)`
heading in `docs/curriculum/DIRECTIVES.md` for the owner to curate. Research
mode is read-only against the codebase (no content edits) and commits
directly to `main` — no branch, no PR.
