# Aspire Sports Curriculum Content Architecture

## Vision

Every piece of content should be **self-contained and actionable**. A volunteer parent coach with zero sports background should be able to pick up any activity card, session plan, or assessment guide and execute it effectively.

The content works at two levels:
1. **Quick Reference** (during practice) - Scannable, visual, exact words to say
2. **Preparation Guide** (before practice) - Deeper context, rationale, troubleshooting

---

## Content Principles

### 1. Show, Don't Just Tell
- Diagrams for every setup
- Exact dimensions (paces, not feet for quick measuring)
- Player and equipment positions clearly marked

### 2. Script the Coaching
- Exact phrases to say at each step
- Questions to ask players (guided discovery)
- What to look for at each moment

### 3. Layer the Complexity
- Basic version anyone can run
- "If players get it" progressions
- "If players struggle" simplifications

### 4. Connect to Development
- Which skills does this build?
- What should players be able to do after mastering this?
- How does this fit in the developmental journey?

## Activity Card Format

Each activity should include:

### Header (Quick ID)
```
[Activity Name]
Type: warmup | technical | tactical | game | conditioning | cooldown | fun
Difficulty: ⚪ Beginner | 🟡 Intermediate | 🔴 Advanced
Duration: [X] min | Players: [min]-[max] | Space: small/medium/large
Indoor OK: ✓ or ✗
```

### At-a-Glance
```
SKILLS DEVELOPED
• Primary: [main skill]
• Secondary: [other skills]

EQUIPMENT
• [X] balls
• [X] cones (color-coded if needed)
• [optional equipment]

WHAT SUCCESS LOOKS LIKE
"[One sentence describing what you'll see when it's working]"
```

### Setup Diagram
```
Visual representation with:
- Field/court dimensions in paces
- Player positions (○ = player, ● = ball, ▲ = cone)
- Movement arrows
- Zones labeled
```

### How to Play (Scripted)
```
GETTING STARTED
Say: "[Exact words to gather players and explain]"

STEP 1: [Action]
Say: "[What to tell them]"
Look for: [What you're watching for]

STEP 2: [Action]
Say: "[What to tell them]"
Look for: [What you're watching for]

[Continue for each step]
```

### Coaching Moments
```
QUESTIONS TO ASK (During Play)
• "[Question 1]?" → Looking for: [Expected insight]
• "[Question 2]?" → Looking for: [Expected insight]

KEY COACHING POINTS
• [Point 1] - Say: "[Exact phrase]"
• [Point 2] - Say: "[Exact phrase]"

WHAT YOU'LL SEE (Common Mistakes)
• If players [do this] → Say: "[Correction phrase]"
• If players [do this] → Say: "[Correction phrase]"
```

### Progressions
```
IF PLAYERS ARE STRUGGLING
• [Simplification 1]
• [Simplification 2]
Signs to watch: [How you know they're struggling]

IF PLAYERS GET IT QUICKLY
• [Progression 1]
• [Progression 2]
Signs to watch: [How you know they're ready]

VARIATIONS
• [Variation name]: [Brief description]
```

### Time Guide
```
For 5-minute version: [What to focus on]
For 10-minute version: [Full activity]
For 15-minute version: [Add progression X]
```

[1-2 sentences on why this skill is important for development]

• [Skill 1] - should be at Level [X] first
• [Skill 2] - should be at Level [X] first

```

□ [Specific behavior you can see]
□ [Specific behavior you can see]

### Development Tips
```

• [Mistake 1]
  - What you see: [Description]
  - Why it happens: [Root cause]

• [Mistake 2]
  [Same format]

## Content Quality Checklist

Before finalizing any content:

□ Can a first-time coach run this without asking questions?
□ Are exact phrases provided for key moments?
□ Are setup dimensions in paces (not feet/meters)?
□ Is there a visual diagram for setup?
□ Are progressions and simplifications included?
□ Is it clear what success looks like?
□ Are common mistakes and corrections included?
□ Does it connect to developmental skills?
□ Is it appropriate for the target age group?
□ Would it print cleanly on 1-2 pages?
