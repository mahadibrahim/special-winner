## Ages 6-9: Introduction Stage

### Development Focus
- **Primary Goal:** Fall in love with ball and movement
- **Philosophy:** Small-sided play, maximum touches

### Skills to Develop

| Category | Skill | Focus |
|----------|-------|-------|
| **Passing** | Forearm pass | Introduce platform |
| | Setting | Overhead catch and release |
| **Movement** | Shuffle steps | Court movement |
| | Ready position | Athletic stance |
| **Ball control** | Self-toss and catch | Hand-eye coordination |
| | Wall passes | Solo repetitions |

### Practice Structure (30-45 minutes)

| Segment | Duration | Content |
|---------|----------|---------|
| Movement games | 10 min | Tag, relay races |
| Ball handling | 10 min | Self-toss, catches, wall work |
| Partner passing | 10 min | Cooperative rallies |
| Mini games | 10-15 min | 1v1, 2v2 over low net |

### What TO DO
- Use lightweight or trainer volleyballs
- Lower nets significantly
- Allow catching before progressing
- Focus on keeping ball in air
- Celebrate rallies (cooperation)
- Small courts, maximum touches

### What NOT TO DO
- ❌ Regulation height nets
- ❌ Regulation volleyballs (too heavy)
- ❌ Serving from baseline
- ❌ 6v6 format
- ❌ Complex rotations
- ❌ Criticizing missed contacts

## Ages 10-12: Skill Building Stage

### Development Focus
- **Primary Goal:** Develop fundamental techniques
- **Philosophy:** Technical excellence through repetition

### Skills to Develop

| Category | Skill | 10-11 | 12 |
|----------|-------|-------|-----|
| **Passing** | Forearm pass | Platform, angles | Moving platform |
| **Setting** | Overhead | Consistent hands | Target setting |
| **Serving** | Underhand | Consistent | Game serve |
| | Overhand | Introduce | Develop |
| **Attacking** | Approach | Footwork | Timing |
| | Contact | Introduction | Developing |
| **Defense** | Ready position | Athletic base | Quick response |
| | Digging | Introduction | Basic technique |
| **Blocking** | Jump | Introduce timing | Penetration |

### Practice Structure (60-75 minutes)

| Segment | Duration | Content |
|---------|----------|---------|
| Dynamic warm-up | 10 min | Movement + ball handling |
| Passing/setting | 15 min | Partner and target work |
| Serving | 10 min | Technique and accuracy |
| Attacking | 15 min | Approach and contact |
| Game play | 15-20 min | 4v4 or 6v6 modified |
| Cool-down | 5 min | Stretching |

### Court Sizes and Modifications

| Age | Court Size | Format | Serving |
|-----|------------|--------|---------|
| 10-11 | Modified (4m x 8m) | 3v3, 4v4 | In front of baseline |
| 12 | Modified to full | 4v4, 6v6 | Baseline or closer |

### Assessment Benchmarks

| Skill | Emerging | Developing | Competent |
|-------|----------|------------|-----------|
| Forearm pass | Ball not controlled | To general area | To target |
| Set | Inconsistent hands | Basic shape | Accurate |
| Underhand serve | Doesn't cross net | Crosses net | Targeted |
| Overhand serve | Can't execute | Sometimes over | Consistent |
| Approach footwork | Wrong feet | Correct but slow | Fluid |

## Ages 13-15: Development Stage

### Development Focus
- **Primary Goal:** Apply skills in competitive settings
- **Philosophy:** Position introduction with continued fundamentals

### Skills to Develop

| Category | Skill | Description |
|----------|-------|-------------|
| **Passing** | Platform adjustment | Different serve types |
| | Out-of-system passing | Off-speed play |
| **Setting** | Back sets | Behind head |
| | Jump setting | Introduction |
| | Decision making | Who to set |
| **Serving** | Float serve | Develop |
| | Jump serve | Introduce |
| | Serving zones | Target areas |
| **Attacking** | Shots | Tips, roll shots |
| | Hitting zones | Cross, line, tool |
| | Timing variations | Quick, high |
| **Defense** | Reading hitters | Anticipation |
| | Pursuit | Chase balls down |
| **Blocking** | Timing | With setter |
| | Reading | Hitter tendencies |
| | Transition | Block to attack |

### Position Skills Introduction

| Position | Key Skills | Development Focus |
|----------|------------|-------------------|
| **Setter** | Hands, decision-making, leadership | Footwork, consistency |
| **Libero** | Passing, digging, serve receive | Reading, communication |
| **Outside** | Passing, attacking, blocking | All-around skills |
| **Middle** | Quick attacks, blocking | Timing, footwork |
| **Opposite** | Attacking, blocking | Right-side skills |

### Practice Structure (75-90 minutes)

| Segment | Duration | Content |
|---------|----------|---------|
| Warm-up | 10 min | Ball handling, movement |
| Skill work | 20 min | Position-specific |
| Team systems | 20 min | Offense, defense |
| Serve/serve receive | 15 min | Competition |
| Scrimmage | 20 min | 6v6 with coaching |
| Cool-down | 5 min | Recovery |

### What TO DO
- Introduce position preferences (not locked)
- Develop all-around players
- Emphasize communication
- Use video analysis
- Build volleyball IQ
- Track improvement across all skills

### What NOT TO DO
- ❌ Lock players into positions
- ❌ Skip fundamentals for systems
- ❌ Over-specialize training
- ❌ Ignore player preference
- ❌ Excessive competitions

## Ages 16-18: Competitive Stage

### Development Focus
- **Primary Goal:** High-level competition preparation
- **Philosophy:** Position refinement with tactical sophistication

### Advanced Skills

| Category | Skill | Focus |
|----------|-------|-------|
| **Offense** | Complex plays | Combinations |
| | Transition attack | System to attack |
| | Out of system | High ball solutions |
| **Defense** | Rotation defense | Reading, adjusting |
| | Pursuit defense | Saving balls |
| | Blocking schemes | Formations |
| **Serve receive** | Pattern adaptations | Against various serves |
| **Serving** | Tactical serving | Target weaknesses |
| **Mental** | Pressure performance | Close-game composure |
| | Leadership | Communication |

### Practice Structure (90-120 minutes)

| Segment | Duration | Content |
|---------|----------|---------|
| Warm-up | 15 min | Position-specific prep |
| Skill development | 20 min | Advanced technique |
| Team systems | 25 min | Offensive/defensive |
| Scrimmage | 30 min | Competitive play |
| Video review | 15 min | Game analysis |
| Conditioning | 10 min | Sport-specific |
| Cool-down | 5 min | Recovery |

## Key Safety Guidelines

| Topic | Guideline |
|-------|-----------|
| **Surfaces** | Appropriate flooring, ankle support |
| **Net equipment** | Secured, padded posts |
| **Shoulder care** | Arm care program for hitters/servers |
| **Jump training** | Progressive, age-appropriate |
| **Hydration** | Regular breaks |
| **Rest** | Off-season, multi-sport encouraged |
