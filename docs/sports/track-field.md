## European Development Philosophy

European Athletics and World Athletics emphasize that track and field must be adapted for children to promote active, healthy lifestyles while developing future champions.

### Kids' Athletics Program (World Athletics/European Athletics)

The globally-adopted Kids' Athletics program transforms traditional track and field into team-based, engaging activities for children ages 7-15.

| Principle | European Approach | Common US Mistake |
|-----------|-------------------|-------------------|
| **Team Format** | Events scored as teams | Individual-only competition |
| **Multi-Event** | All children do all events | Early event specialization |
| **Adapted Equipment** | Age-appropriate implements | Adult equipment too early |
| **Fun First** | Games and challenges | Traditional drills |
| **Late Specialization** | Event focus at 15+ | Specialize at 12 |
| **Movement Literacy** | General athleticism first | Sport-specific only |

### Youth Physical Development Model

The YPD model emphasizes development-based over age-based training:

| Age | Development Priority |
|-----|---------------------|
| **Before 7** | Basic movement skills, coordination, bone/muscle development |
| **7-11** | General athleticism, speed, agility, balance, multiple sports |
| **11-15** | Skill refinement, strength introduction, event exploration |
| **15+** | Event specialization, performance training |

> "Before the age of 7 is a critical time for developing basic movement skills, coordination, balance, and strong bones and muscles. These accomplishments will set the foundation for future success in sports."
> — European Athletics Youth Development

## FUNdamentals Stage (Ages 5-9)

### Development Focus
- **Primary Goal:** Movement literacy
- **Philosophy:** Fun, varied movement experiences

### Skills to Develop

| Category | Skill | Activities |
|----------|-------|------------|
| **Running** | Sprinting | Short races, relays |
| | Agility | Tag games, shuttle runs |
| | Endurance | Fun runs (distance varies) |
| **Jumping** | Horizontal | Standing long jump |
| | Vertical | Jump and reach games |
| | Approach | 3-5 step approaches |
| **Throwing** | Overhand | Soft implements |
| | Underhand | Bean bags, light balls |
| | Rotational | Introduction (turns) |

### Practice Structure (45-60 minutes)

| Segment | Duration | Content |
|---------|----------|---------|
| Warm-up | 10 min | Running games, tag |
| Running activities | 15 min | Sprints, relays |
| Jumping activities | 10 min | Games, challenges |
| Throwing activities | 10 min | Light implements |
| Cool-down games | 10 min | Fun activities |

### What TO DO
- Every session includes running, jumping, throwing
- Use games and challenges
- Rotate through all events
- Focus on movement quality
- Celebrate effort and improvement
- Keep everyone active

### What NOT TO DO
- ❌ Specialize in one event
- ❌ Heavy implements
- ❌ Complex technique instruction
- ❌ Long-distance running emphasis
- ❌ Standing around waiting
- ❌ Performance pressure

## Learning to Train Stage (Ages 9-12)

### Development Focus
- **Primary Goal:** Develop fundamental skills in all events
- **Philosophy:** Exposure to full range of events

### Event Groups and Skills

#### Sprints/Hurdles
| Skill | 9-10 | 11-12 |
|-------|------|-------|
| Start | Standing start | 3-point start |
| Acceleration | Basic mechanics | Drive phase |
| Max velocity | Arm action | Full technique |
| Hurdles | Introduction (low) | Basic rhythm |

#### Jumps
| Event | 9-10 | 11-12 |
|-------|------|-------|
| Long Jump | Short approach | Full approach intro |
| High Jump | Scissors jump | Flop introduction |
| Triple Jump | Hop-step-jump intro | Basic rhythm |
| Pole Vault | Not recommended | Very basic intro |

#### Throws
| Event | 9-10 | 11-12 |
|-------|------|-------|
| Shot Put | Light shot (4-6 lb) | Glide introduction |
| Discus | Light disc | Basic technique |
| Javelin | Turbo jav | 3-5 step throw |

#### Distance
| Focus | 9-10 | 11-12 |
|-------|------|-------|
| Aerobic | Fun runs, games | Progressive distance |
| Pacing | Introduction | Basic concept |
| Max distance | 800m | 1500m |

### Practice Structure (60-75 minutes)

| Segment | Duration | Content |
|---------|----------|---------|
| Dynamic warm-up | 15 min | Running drills, skips, bounds |
| Event rotation 1 | 20 min | Two event groups |
| Event rotation 2 | 20 min | Two event groups |
| Cool-down | 10 min | Easy jog, stretching |

### Multi-Event Approach

Every athlete should experience:
- 2-3 running events per season
- 2-3 jumping events per season
- 2-3 throwing events per season

## Training to Train Stage (Ages 12-16)

### Development Focus
- **Primary Goal:** Technical development in event groups
- **Philosophy:** Guided specialization with continued variety

### Event Group Development

#### Sprints/Hurdles
| Skill | 12-14 | 15-16 |
|-------|-------|-------|
| Block starts | Introduction | Refinement |
| Acceleration | 30-40m focus | Race-specific |
| Maximum velocity | Technical work | Speed endurance |
| Hurdles | 3-step rhythm | Event-specific |

#### Jumps
| Event | 12-14 | 15-16 |
|-------|-------|-------|
| Long Jump | Full approach | Technical refinement |
| High Jump | Flop development | Bar clearance |
| Triple Jump | Phase development | Event specialization |
| Pole Vault | Grip, carry, plant | Full jump |

#### Throws
| Event | 12-14 | 15-16 |
|-------|-------|-------|
| Shot Put | Glide/rotational intro | Technique choice |
| Discus | Full throw | Power development |
| Javelin | Full approach | Technical refinement |
| Hammer | Introduction | Basic technique |

#### Middle Distance/Distance
| Focus | 12-14 | 15-16 |
|-------|-------|-------|
| Aerobic base | Foundation | Significant volume |
| Threshold | Introduction | Specific work |
| Race tactics | Basic | Advanced |
| Cross training | Encouraged | Maintained |

### Practice Structure (75-90 minutes)

| Segment | Duration | Content |
|---------|----------|---------|
| Warm-up | 15 min | Event-specific |
| Technical work | 25 min | Primary event group |
| Secondary events | 20 min | Maintain variety |
| Conditioning | 20 min | Event-appropriate |
| Cool-down | 10 min | Recovery |

### Growth Spurt Considerations (Critical)

During growth spurts:
- Reduce jump training volume 20-30%
- Switch from high-impact to technique focus
- Monitor for apophysitis (knee, heel pain)
- Maintain flexibility work
- Be patient with coordination changes

## Key Safety Guidelines

| Topic | Guideline |
|-------|-----------|
| **Throwing safety** | Clear throwing sector |
| **Implement weight** | Age-appropriate |
| **Jump landing** | Proper landing areas |
| **Pole vault** | Certified equipment, trained coaches |
| **Heat management** | Hydration, rest |
| **Growth monitoring** | Adjust training during growth spurts |
| **Overuse prevention** | Volume management, variety |
