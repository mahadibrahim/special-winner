## Ages 4-6: Tee Ball

### Development Focus
- **Primary Goal:** Introduction to baseball/softball
- **Philosophy:** Fun, fitness, fundamentals - no competition

### Skills to Develop

| Category | Skill | Description |
|----------|-------|-------------|
| **Hitting** | Stance | Athletic position, balanced |
| | Swing | Level swing through ball |
| | Contact | Hit ball off tee consistently |
| **Throwing** | Grip | Two fingers on top |
| | Motion | Arm back, step, throw |
| | Accuracy | Toward partner/target |
| **Catching** | Glove position | "Alligator mouth" |
| | Ground balls | Get in front |
| | Pop flies | Two hands |
| **Base running** | Running | Straight to base |
| | Stopping | On the base |

### Practice Structure (45-60 minutes)

| Segment | Duration | Content |
|---------|----------|---------|
| Warm-up | 10 min | Running games, stretching |
| Throwing/catching | 10 min | Partner work (short distance) |
| Hitting stations | 15-20 min | Tee work, soft toss |
| Fielding games | 10 min | Rolling ground balls |
| Base running | 5-10 min | Fun relay races |

### What TO DO
- Every player hits every inning
- Rotate positions every inning
- Use soft or reduced impact balls
- Celebrate all contact with ball
- Keep instructions simple (one thing at a time)
- Make it FUN

### What NOT TO DO
- ❌ Keep score
- ❌ Have "outs"
- ❌ Strikeouts
- ❌ Put kids in outfield alone
- ❌ Long waits between at-bats
- ❌ Complicated rules
- ❌ Yell corrections

### Assessment Benchmarks

| Skill | Emerging | Developing | Competent |
|-------|----------|------------|-----------|
| Hitting off tee | Misses/tips ball | Makes contact | Solid contact |
| Throwing | Can't reach partner | Reaches 15 feet | Accurate 20 feet |
| Catching | Afraid of ball | Traps with body | Uses glove properly |
| Running | Wrong direction | To correct base | Touch and return |

## Ages 7-8: Coach Pitch

### Development Focus
- **Primary Goal:** Track moving ball
- **Philosophy:** Skill building with gradual competition

### Skills to Develop

| Category | Skill | Description |
|----------|-------|-------------|
| **Hitting** | Timing | Track pitch to contact |
| | Swing path | Level through zone |
| | Bat control | Hit to all fields |
| **Throwing** | Crow hop | Add momentum to throws |
| | Accuracy | Hit target consistently |
| | Distance | Increase range |
| **Fielding** | Ready position | Athletic stance |
| | Ground balls | Through the ball |
| | Fly balls | Drop step, track |
| | Throwing after fielding | Connect the play |
| **Base running** | Leads | When allowed |
| | Reading plays | Stop or advance |

### Practice Structure (60-75 minutes)

| Segment | Duration | Content |
|---------|----------|---------|
| Dynamic warm-up | 10 min | Arm care, running |
| Throwing progression | 10 min | Increasing distance |
| Infield/outfield | 15 min | Position-specific |
| Hitting | 20 min | Stations: tee, soft toss, BP |
| Live play | 15 min | Game situations |
| Cool-down | 5 min | Stretching, team talk |

### What TO DO
- Use low-compression balls when possible
- Rotate all positions (including catcher, pitcher awareness)
- Limit innings pitched (for awareness, not competition)
- Equal playing time
- Teach proper throwing mechanics
- Celebrate improvement

### What NOT TO DO
- ❌ Position specialization
- ❌ Keeping players in outfield all game
- ❌ Focus on wins
- ❌ Allow excessive strikeouts (modify rules)
- ❌ Long practices without activity
- ❌ Over-coaching at plate

### Assessment Benchmarks

| Skill | Emerging | Developing | Competent |
|-------|----------|------------|-----------|
| Hit moving pitch | Swings late/early | Makes contact 40% | Makes contact 60%+ |
| Throw to first | Can't reach | Reaches on bounce | Reaches in air |
| Field ground ball | Ball goes through | Stops most | Clean fielding |
| Catch fly ball | Avoids | Catches some | Catches most |

## Ages 9-11: Minor/Kid Pitch

### Development Focus
- **Primary Goal:** Fundamental competency
- **Philosophy:** Develop all skills with introduction to player pitching

### Skills to Develop

| Category | Skill | Description |
|----------|-------|-------------|
| **Hitting** | Pitch selection | Swing at strikes |
| | Power | Drive ball with intent |
| | Situational | Move runners |
| **Pitching** | Fastball | Command and control |
| | Change-up | Introduction |
| | Mechanics | Safe, repeatable delivery |
| **Catching** | Receiving | Framing basics |
| | Blocking | Balls in dirt |
| | Throwing | To bases |
| **Fielding** | Double plays | Footwork and feeds |
| | Cutoffs/relays | Positioning |
| | Communication | Calling fly balls |
| **Base running** | Leads and steals | Reading pitcher |
| | Tagging up | When appropriate |
| | Sliding | Proper technique |

### Practice Structure (75-90 minutes)

| Segment | Duration | Content |
|---------|----------|---------|
| Dynamic warm-up | 10 min | Throwing progression |
| Position work | 20 min | Infield, outfield, battery |
| Team defense | 15 min | Cutoffs, situations |
| Hitting | 25 min | BP, cage work, stations |
| Baserunning | 10 min | Leads, steals, reads |
| Game situations | 10 min | Scrimmage or drills |

### Pitching Guidelines (Critical)

| Age | Max Pitches/Day | Max Pitches/Week | Rest Requirements |
|-----|-----------------|------------------|-------------------|
| 9-10 | 75 | 175 | 1-20: 0 days; 21-35: 1 day; 36-50: 2 days; 51-65: 3 days; 66+: 4 days |
| 11-12 | 85 | 200 | Same structure as above |

**Breaking pitches (curveball, slider): NOT recommended until 13+**

### What TO DO
- Track pitch counts religiously
- Rotate pitchers
- Teach proper pitching mechanics
- Develop catchers at same pace as pitchers
- Play multiple positions
- Use game situations in practice

### What NOT TO DO
- ❌ Exceed pitch count limits
- ❌ Teach breaking balls
- ❌ Specialize positions
- ❌ Play year-round
- ❌ Ignore arm pain
- ❌ Over-schedule games

### Assessment Benchmarks

| Skill | Emerging | Developing | Competent | Advanced |
|-------|----------|------------|-----------|----------|
| Batting average | <.200 | .200-.300 | .300-.400 | .400+ |
| Strike % (pitching) | <50% | 50-60% | 60-70% | 70%+ |
| Fielding % | <.800 | .800-.900 | .900-.950 | .950+ |
| Throwing accuracy | Often off | Usually good | Accurate | On target |

## Ages 12-14: Major/Competitive

### Development Focus
- **Primary Goal:** Refined skill application
- **Philosophy:** Competition with continued development

### Skills to Develop

| Category | Skill | Description |
|----------|-------|-------------|
| **Hitting** | Pitch recognition | Identify pitch type |
| | Approach | Count-based adjustments |
| | Power vs contact | Situational decisions |
| **Pitching** | Secondary pitches | Change-up development |
| | Location | Pitching to spots |
| | Sequencing | Setting up hitters |
| **Defense** | Advanced reads | Pre-pitch positioning |
| | Situational play | Multiple scenarios |
| | Communication | Team defense |
| **Mental** | Pressure management | Big moment composure |
| | Self-correction | In-game adjustments |

### Pitching Guidelines

| Age | Max Pitches/Day | Rest Requirements |
|-----|-----------------|-------------------|
| 13-14 | 95 | Similar to 11-12 with extended ranges |

**Breaking pitches:** May introduce curveball at 13+ with proper mechanics and limited use.

### Practice Structure (90-120 minutes)

| Segment | Duration | Content |
|---------|----------|---------|
| Warm-up/arm care | 15 min | Progressive throwing |
| Position-specific | 25 min | Advanced skills |
| Team defense | 20 min | Situations, bunt defense |
| Hitting | 30 min | Live BP, cage, mental |
| Game situations | 20 min | Pressure scenarios |
| Conditioning | 10 min | Sport-specific |

### What TO DO
- Video analysis
- Mental skills development
- Position preferences (not locked)
- Strength training introduction
- Advanced strategy
- Showcase preparation (high school)

### What NOT TO DO
- ❌ Ignore growth-related injury risk
- ❌ Year-round play
- ❌ Excessive pitching
- ❌ Skip fundamentals
- ❌ Over-specialize positions

## Arm Care Program

### Daily Throwing Progression

| Phase | Distance | Intensity |
|-------|----------|-----------|
| Warm-up | 30-60 ft | Easy |
| Progressive | 60-90 ft | Medium |
| Long toss | 90-150 ft | Controlled effort |
| Pull down | 60-90 ft | Game intensity |
| Cool down | 30 ft | Easy |

### Arm Strengthening (Ages 12+)

| Exercise | Focus |
|----------|-------|
| Band exercises | Shoulder stability |
| Wrist curls | Forearm strength |
| Shoulder exercises | Rotator cuff |
| Core work | Power generation |

## Key Safety Guidelines

| Topic | Guideline |
|-------|-----------|
| **Pitch counts** | Strictly enforced |
| **Rest** | Minimum rest between pitching appearances |
| **Breaking balls** | Not until 13+ |
| **Arm pain** | Stop immediately, seek evaluation |
| **Catching** | Limit innings, especially with pitching |
| **Sliding** | Teach proper technique before use |
| **Equipment** | Proper batting helmet, cup, cleats |
