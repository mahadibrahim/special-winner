## Flag Football: Ages 5-10

### Development Focus
- **Primary Goal:** Love the game, develop athleticism
- **Philosophy:** Football skills without contact risk

### Skills to Develop

| Category | Skill | Ages 5-7 | Ages 8-10 |
|----------|-------|----------|-----------|
| **Throwing** | Grip | Introduce | Develop |
| | Stance | Basic | Proper mechanics |
| | Accuracy | Short passes | 10-15 yards |
| **Catching** | Hand position | Basic | Over shoulder |
| | Ball tracking | Stationary | On the move |
| | Route running | Straight | Basic cuts |
| **Running** | Ball security | Two hands | Proper carry |
| | Vision | Find space | Read defense |
| | Change direction | Basic cuts | Sharp cuts |
| **Flag pulling** | Technique | Chase and pull | Angle pursuit |
| | Position | Get in front | Hip level |

### Practice Structure: Flag (45-60 minutes)

| Segment | Duration | Content |
|---------|----------|---------|
| Dynamic warm-up | 10 min | Movement games |
| Skill stations | 20 min | Throwing, catching, flag pulling |
| Team plays | 15 min | 3-5 simple plays |
| Scrimmage | 10 min | 5v5 or 7v7 |
| Cool-down | 5 min | Stretching, team talk |

### What TO DO
- Maximum participation (small-sided games)
- Rotate positions frequently
- Focus on athleticism over football-specific
- Keep it fun and active
- Encourage all players to handle the ball
- Use age-appropriate equipment

### What NOT TO DO
- ❌ Specialization
- ❌ Complex playbooks
- ❌ Extensive film study
- ❌ Position-based cuts
- ❌ Over-coaching
- ❌ Any contact or contact drills

## Rookie Tackle: Ages 8-10 (Bridge Program)

### Development Focus
- **Primary Goal:** Introduction to contact in controlled environment
- **Philosophy:** Safe progression from flag to tackle

### Contact Progression (USA Football System)

| Level | Description | When to Introduce |
|-------|-------------|-------------------|
| Level 1 | Fit positions | Day 1 |
| Level 2 | Control emphasis | Week 1-2 |
| Level 3 | Block/defeat with pads | Week 2-3 |
| Level 4 | Thud (above waist) | Week 3-4 |
| Level 5 | Live (limited) | After mastery |

### Stance Recommendation

**Use two-point stance for all blocking and tackling.**

Research shows three/four-point stances increase head impact exposure. All USA Football techniques can be taught from two-point stance.

### Skills to Develop

| Category | Skill | Focus |
|----------|-------|-------|
| **Blocking** | Fit position | Hand placement |
| | Drive block | Leg drive |
| | Protection | Pass blocking base |
| **Tackling** | Approach angle | Path to ball carrier |
| | Breakdown | Athletic position |
| | Shoulder contact | Head out, through ball |
| | Wrap and drive | Complete tackle |
| **Ball carrier** | Ball security | High and tight |
| | Contact balance | Stay on feet |
| **Overall** | Football IQ | Understanding game |

### Practice Structure (60-75 minutes)

| Segment | Duration | Content |
|---------|----------|---------|
| Dynamic warm-up | 10 min | Football movements |
| Position skills | 15 min | Non-contact technique |
| Contact progression | 15 min | Controlled, specific drills |
| Team concepts | 15 min | Play installation |
| Scrimmage | 10-15 min | Thud or live (limited) |
| Cool-down | 5 min | Recovery, debrief |

### Practice Guidelines (Safety Critical)

| Element | Guideline |
|---------|-----------|
| **Full contact** | Maximum 40 min/week |
| | Maximum 10 min/practice |
| **Total practice** | Maximum 105 min |
| **Acclimatization** | First 5 days: no contact |

## Youth Tackle: Ages 11-14

### Development Focus
- **Primary Goal:** Develop complete football player
- **Philosophy:** Skill development with progressive competition

|-------|-------|-------|
| Run blocking | Base blocks | Combo blocks |
| Pass protection | Basic sets | Mirror technique |
| Pulling | Introduce | Execute |

|-------|-------|-------|

### Practice Structure (90-105 minutes)

| Segment | Duration | Content |
|---------|----------|---------|

| Day | Focus | Contact Level |

## Tackling Progression (Heads Up Football)

### Shoulder Tackling System

| Phase | Skill | Coaching Points |
|-------|-------|-----------------|
| **1. Approach** | Breakdown | Athletic position, buzz feet |
| **2. Position** | Club and rip | Hands through hips |
| **3. Contact** | Shoot hips | Drive through contact |
| **4. Finish** | Wrap and drive | Wrap arms, drive legs |

### Key Principles

1. **Head out of contact** - Never lead with helmet
2. **See what you hit** - Eyes up through contact
3. **Shoulder contact** - Primary contact point
4. **Hip explosion** - Power from legs
5. **Arm wrap** - Complete the tackle

## Assessment Benchmarks

### Flag Football

| Skill | Emerging | Developing | Competent |
|-------|----------|------------|-----------|
| Throwing | Can't spiral | Sometimes spirals | Consistent spirals |
| Catching | Drops most | Catches 50% | Catches 80% |
| Flag pulling | Can't catch | Catches sometimes | Consistent pulls |
| Ball security | Drops often | Sometimes loses | Secure carry |

### Tackle Football

| Domain | Skill | Emerging | Developing | Competent | Advanced |
|--------|-------|----------|------------|-----------|----------|
| Tackling | Form | Ducks head | Head up, misses | Completes most | Dominates |
| Blocking | Drive | Gets moved | Stalemate | Moves defender | Controls |
| Ball skills | Catching | 50% | 70% | 85% | 95% |
| Football IQ | Assignments | Often wrong | Sometimes wrong | Usually correct | Anticipates |

## Key Safety Guidelines

| Topic | Guideline |
|-------|-----------|
| **Helmet fit** | Properly fitted, certified |
| **Contact limits** | Follow weekly maximums strictly |
| **Tackling technique** | Heads Up Football methods |
| **Stance** | Two-point for youth development |
| **Heat safety** | Acclimatization, hydration |
| **Concussion protocol** | Recognition, removal, return to play |
| **Equipment** | All pads properly fitted |

### Concussion Protocol

1. **Recognize** - Know the signs
2. **Remove** - When in doubt, sit them out
3. **Refer** - Medical evaluation required
4. **Return** - Gradual return to play protocol
